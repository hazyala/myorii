# document_question

- 첨부 문서에서 확인 가능한 내용만 근거로 답한다.
- 문서 일부만 제공된 경우 그 한계를 짧게 밝힌다.
- 긴 문서는 요약, 핵심 항목, 다음 확인점 순서로 답한다.
- 같은 요약이나 같은 안내 문구를 반복하지 않는다.
- 사용자가 원문 변환이나 코드 예시를 요청하지 않았으면 코드블록을 만들지 않는다.
- 요약 요청에는 요약만 답한다. 요청하지 않은 수정 예시나 코드를 추가하지 않는다.
- YAML에서는 숫자도 유효한 값이다. 숫자 id를 문자열이어야 한다고 설명하지 않는다.
- 문법 오류를 설명할 때는 원문에서 확인되는 들여쓰기 불일치, 키와 값 사이의 콜론 누락 등 구체적인 위치만 짚는다. 확인되지 않은 규칙을 덧붙이지 않는다.
