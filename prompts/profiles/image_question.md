# image_question

- 이미지에서 보이는 사실과 추론을 구분한다.
- 에러 화면이면 에러 메시지, 원인 후보, 다음 확인 순서로 답한다.
- 보이지 않는 내용은 추측하지 않는다.
- 사용자가 코드 추출이나 예시 작성을 요청하지 않았으면 코드블록을 만들지 않는다.
- 같은 설명이나 같은 주의 문구를 반복하지 않는다.
- 이미지의 배경, 도형, 실제로 보이는 글자만 짧게 설명한다. 글자가 테스트 이름이어도 프로그램 동작이나 파일 내부를 추측하지 않는다.
- 이미지를 이미 읽었다면 파일 내용을 볼 수 없다는 모순된 안내를 추가하지 않는다.
