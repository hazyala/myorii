# 수동 테스트 케이스

이 문서는 사용자가 직접 수행할 테스트 목록이다. AI가 수행한 테스트 결과를 기록하는 문서가 아니며, 기능별 구현 상태를 확인하고 이후 디버깅과 오류 수정을 추적하기 위한 기준 목록으로 사용한다.

테스트 상태는 `미실행`, `성공`, `실패`, `이슈 발견` 중 하나를 우선 사용한다. 첨부 handler 자체 문제가 아닌 응답 중복, 스트리밍, 메시지 렌더링, LLM 응답 포맷 문제도 이 문서에 함께 기록한다. AI가 로컬에서 수행한 코드 검증 결과는 이 문서의 `성공` 상태로 기록하지 않고, 사용자가 직접 확인한 결과만 반영한다.

## 향후 기능 테스트 작성 규칙

## 채팅 할일·메모 도구 (2026-10-04)

1. `/todo`만 입력 → 일반 색상. 스페이스 → 태그만 파랑. `/memo `는 보라. 지우기/되돌리기/붙여넣기/한글 입력 후 원문이 유지되는지 확인.
2. `/todo 보고서 보내기 추가해줘` → 채팅 저장 확인, 할일 탭에 새 항목. 완료된 기존 항목을 두고 `/todo 오늘 뭐 해야 하지?` → 미완료만 표시.
3. `/memo 방금 답변 메모에 저장해줘` → 직전 답변 본문 저장, 메모 탭에서 확인. 사용자 발언을 남기고 `/todo 방금 한말 요약해서 할일에 적어줘` → 원문에 근거한 행동 저장. 새 대화에서는 없는 이전 대화를 저장하지 않음.
4. 제목 `부산 출장`, 본문 `부산 회의는 오후 3시`인 메모로 `/memo 부산 미팅 언제야?` → 3시와 참고 제목. `/memo 화성 여행 일정 찾아줘` → 찾지 못했습니다.
5. 태그 없는 `할일에 우유 사기 추가해줘`, `오늘 뭐 해야 하지?`, `메모에서 부산 미팅 찾아줘`도 확인.
