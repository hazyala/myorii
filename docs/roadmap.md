# 🗺️ Myorii Roadmap

Myorii의 장기적인 개발 방향과 버전별 목표를 정의한다.

---

# 프로젝트 목표

Myorii는 메뉴바 및 시스템 트레이에 상주하며,

사용자가 가장 자주 사용하는 생산성 기능을 창 이동 없이 즉시 사용할 수 있도록 돕는 데스크톱 컴패니언 애플리케이션을 목표로 한다.

# V2 - Model Tools & Integrations

## 목표

* 연결 추가·목록·해제 UI와 제공자별 지원 방식 검토
* 인증 정보 보관과 도구 실행 권한·실패 처리
* 모델 요청에 도구를 연결하고 실제 호출 결과를 대화에 반영

현재는 설정의 구현 예정 안내만 제공한다. MCP 서버 연결, 커넥터 인증, 플러그인 실행은 구현되지 않았다.

# 장기 비전

Myorii는 단순한 AI 채팅 앱이 아니다.

사용자가 가장 자주 사용하는 생산성 기능을 하나의 작은 메뉴바 친구 안에 담아,

작업 흐름을 끊지 않고 즉시 도움을 받을 수 있는 데스크톱 컴패니언을 목표로 한다.

---

# 현재 진행 상태 요약

V1의 메뉴바 진입점, 채팅, 네이밍, 이미지 분석, 첨부 요약, 로컬 저장 구조, 할일, 메모의 기본 흐름은 구현되어 있다. 세부 구현 목록은 이 문서 상단의 `현재 진행 상황`을 기준으로 관리한다.

남은 V1 안정화 항목은 실제 외부 API 검증, 자동 시작 설정, 사용자 화면 직접 조작 검증과 응답 품질 점검이다. 모델 도구 연결과 기기간 동기화는 각각 V2, V3 범위다.
