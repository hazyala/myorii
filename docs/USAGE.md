# 채팅·할일·메모 사용 예

Myorii는 작업 옆에서 질문과 기록을 이어가는 작은 고양이 컴패니언이라는 기존 컨셉을 유지한다. 캐릭터의 눈 깜빡임·꼬리 움직임 등은 로드맵에 있고 현재 기능과 구분한다.

## 채팅

Enter 전송, Shift+Enter 줄바꿈. 응답의 코드·네이밍 블록을 클릭하면 클립보드로 복사한다. 대화 기록 저장 스위치가 켜진 대화를 세션 목록에서 다시 열 수 있다. 설정에서 제공자와 모델을 선택한다. 선택 모델은 텍스트·이미지 요청에 공통 적용된다.

## 로컬 도구

- `할일에 우유 사기 추가해줘`
- `/todo 오늘 뭐 해야 하지?` — 미완료 항목 조회
- `/memo 부산 미팅 언제야?` — 관련 메모 검색, 출처 제목 링크로 편집 화면 진입
- `/memo 방금 답변 메모에 저장해줘`
- `/todo 우유 사기를 두유 사기로 수정해줘`
- `/memo 출장 일정 본문에서 준비물 문장을 지워줘` — 메모 전체 삭제와 구분
- `/memo #2 삭제해줘` — 후보에서 특정 ID 지정

태그 뒤에 스페이스가 있어야 활성화된다. 공백 없는 `/memo괜찮아?`는 일반 텍스트다. 모델 계획이 잘못됐거나 대상이 없으면 변경하지 않는다. 같은 이름이 여러 개면 후보를 확인한다. 완료 상태 전환은 할일 화면에서 한다.

## 첨부 범위

| 형식 | 전달하는 내용 / 한계 |
|---|---|
| PNG, JPG, JPEG, GIF, BMP | 이미지 handler의 인코딩과 제공자별 이미지 요청. 모델의 이미지 입력 지원 필요 |
| TXT, MD, JSON, YAML, YML | 제한된 길이의 텍스트 |
| CSV, TSV | 컬럼·샘플 행 |
| PDF | 일부 페이지 텍스트, 스캔 OCR 없음 |
| DOCX | 일부 문단·표 텍스트, 서식·주석·변경 추적 분석 없음 |
| XLSX | 시트·컬럼·샘플 행, 수식 재계산·피벗·차트 분석 없음 |
| PPTX | 슬라이드 텍스트, 디자인·발표자 노트 분석 없음 |

추출 맥락에는 읽은 범위와 한계가 포함된다. 첨부 원본 경로는 로컬에 남고 외부 API를 선택하면 추출 맥락·이미지가 제공자에게 전달된다. 이미지 전달 형식은 local/cloud client가 각각 처리한다.

## 설정과 종료

테마·언어·모델 선택은 재시작 후 복원한다. API 키는 macOS Keychain에서 저장·삭제한다. 모델 다운로드 버튼은 Ollama 라이브러리 웹페이지를 열며 앱 안의 자동 설치기가 아니다. 자동 시작 스위치는 아직 OS 설정에 연결하지 않았다. 설정 화면의 앱 종료로 메뉴바 프로세스를 종료한다.
