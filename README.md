# 🐈 Myorii

> 메뉴바에 사는 작은 고양이 생산성 도우미

Myorii는 macOS 메뉴바 및 Windows 시스템 트레이에 상주하며, 사용자가 가장 자주 사용하는 생산성 기능을 창 이동 없이 즉시 사용할 수 있도록 돕는 로컬 LLM 기반 데스크톱 컴패니언 애플리케이션입니다.

---

# ✨ 프로젝트 소개

개발 작업이나 문서 작업 중에는 다음과 같은 불편함이 자주 발생합니다.

* 변수명, 함수명, 파일명을 정하기 위해 번역기나 AI를 반복적으로 열어야 함
* 간단한 질문을 하기 위해 새로운 브라우저 탭을 열어야 함
* 메모를 위해 별도 앱을 실행해야 함
* 여러 생산성 도구를 오가며 작업 흐름이 끊김

Myorii는 이러한 문제를 해결하기 위해 메뉴바에 항상 상주하며, 작은 팝업 창 하나로 네이밍, 채팅, 메모 기능을 제공합니다.

# ▶ 실행 방법

## 가상환경 생성

```bash
python3 -m venv .venv
```

## 활성화

```bash
source .venv/bin/activate
```

## 패키지 설치

```bash
pip install -r requirements.txt
```

## Ollama 실행

```bash
ollama serve
```

## 모델 다운로드

```bash
ollama pull qwen3-vl:4b-instruct
```

## 실행

개발 중에는 아래 명령으로 실행한다.

```bash
python main.py
```

현재 구현 기준으로 Myorii 메뉴바 아이콘을 클릭하면 메인 창이 바로 토글된다.

## macOS 앱 번들 빌드

```bash
PYINSTALLER_CONFIG_DIR=/tmp/myorii_pyinstaller .venv/bin/pyinstaller packaging/macos/Myorii.spec --noconfirm --clean
open -n dist/Myorii.app
```

Myorii는 중복 메뉴바 아이콘 생성을 막기 위해 단일 실행 잠금을 사용한다. 새로 빌드한 앱을 확인할 때는 기존 Myorii 프로세스를 먼저 종료한 뒤 실행한다.

* 첫 번째 클릭: 아이콘 위치 근처에 메인 창 표시
* 두 번째 클릭: 메인 창 닫기
* Header의 `×` 버튼: 메인 창 닫기
* 이미 실행 중인 상태에서 다시 실행하면 새 프로세스는 바로 종료되어 메뉴바 아이콘이 중복 생성되지 않는다.

메뉴바 아이콘은 현재 36px 기준으로 렌더링한다.

## 모델 선택과 API 연결

설정의 **AI 모델 → 제공자**에서 **Ollama 로컬 모델 / API** 중 하나를 선택한다. API 모드에서는 API 서비스를 OpenAI(GPT), Google(Gemini), Anthropic(Claude) 중 선택한다. 제공자와 모델 선택은 로컬 SQLite에 저장되며 재실행 후 복원된다.

* Ollama: **모델 관리**에서 실제 설치 목록 새로고침, 모델 선택, 사용하지 않는 모델 삭제를 지원한다. **모델 다운로드** 버튼은 Ollama 모델 라이브러리 페이지를 연다. 설치 후 목록을 새로고침한다. 현재 선택한 모델은 다른 모델을 먼저 선택한 뒤 삭제한다.
* API: **API** 버튼과 API 서비스를 선택하고 화면의 API 키 입력란에서 키를 입력한 뒤 **키 저장**을 누른다. 키 저장 후 채팅용 모델 목록이 자동으로 표시된다. 드롭다운에서 모델을 선택하며 **목록 새로고침**으로 다시 조회할 수 있다. 모델 이름 직접 입력은 지원하지 않는다.
* API 키는 macOS 키체인(`Myorii API`)에만 저장한다. SQLite와 대화 기록에는 키를 저장하지 않는다. **저장된 키 삭제**로 제거할 수 있다.
* 외부 API 모드에서는 대화 이력과 첨부 참고 내용, 이미지가 선택한 제공자에게 전송된다. API 사용 요금과 모델별 접근 권한은 해당 제공자 계정에 따른다. 로컬 모드는 Ollama에서 처리한다.
* OpenAI Responses, Gemini streamGenerateContent, Anthropic Messages의 스트리밍을 사용한다. 이미지 첨부는 PNG로 정규화하며, 선택 모델이 이미지 입력을 지원해야 한다.

2026-10-04 검증: 자동 테스트 28개 통과. 실제 Ollama `gemma3:4b` 모델 선택 및 응답 확인. 외부 API는 사용자 키가 등록되지 않아 실제 계정 호출은 미검증이며, 요청 구성·스트리밍·인증 오류·모델 목록·이미지 전달은 재현 응답으로 검증했다.

## 현재 UI 구현 범위

현재 메인 창은 채팅, 할일, 메모 탭이 포함된 PyQt6 팝오버 화면이다.

* 채팅, 할일, 메모 탭은 하나만 선택된다.
* 선택된 탭에 맞춰 중앙 컨텐츠 영역이 전환된다.
* 채팅 탭은 선택한 Ollama 또는 API 모델과 연결되어 사용자 메시지와 AI 응답을 표시한다.
* 채팅 요청은 `IntentRouter`, `ModelRouter`, `PromptProfileResolver`, `ResponseFormatter`를 거쳐 처리한다.
* 모든 채팅 응답은 설정에서 선택한 제공자와 모델로 생성한다. 기본 로컬 모델은 `qwen3-vl:4b-instruct`다.
* 텍스트/이미지 요청 모두 선택 모델을 유지한다. 이미지 입력 지원 여부는 선택 모델에 따른다.
* 앱 시작 시 모델 워밍업을 백그라운드에서 시도하고, 채팅 요청은 `keep_alive=30m`로 모델을 유지한다. Ollama가 실행 중이 아니면 워밍업 실패는 조용히 무시하고 기존 요청 시점 에러 흐름을 유지한다.
* 채팅 요청 시 Ollama가 실행 중이 아니면 `Ollama가 실행 중이 아니에요. Ollama를 실행한 뒤 다시 시도해주세요.`라고 안내한다.
* 응답은 워커 스레드에서 토큰 단위로 수신하고, UI에는 스트리밍으로 반영된다.
* Assistant 응답은 완료 시점에 Markdown으로 렌더링한다.
* 파일명, 함수명, 변수명, 클래스명, 명령어, Python/Java/HTML/CSS/C 계열 코드, SQL, 정규식, 짧은 단어 번역처럼 바로 복사해 쓰는 개발 산출물은 복사 가능한 블록으로 표시하고, 클릭 시 클립보드에 복사되며 `복사됨` 토스트를 표시한다.
* 여러 후보는 후보별 코드블록으로 분리하고, 하나의 언어 코드 스니펫, SQL, 셸 스크립트는 줄바꿈과 들여쓰기를 유지한 하나의 코드블록으로 유지한다.
* 요약, 분석, 문서 내용 설명, 일상 대화는 사용자가 코드나 명령어를 요청하지 않는 한 일반 문장으로 표시한다.
* 응답 대기 중에는 빨간 발바닥 3개가 순차로 튀는 인디케이터를 표시하고, 첫 토큰 수신 시 텍스트로 전환한다.
* 현재 세션의 대화 맥락은 앱 실행 중 `ChatService`가 유지한다.
* Header에는 인터넷 연결 상태에 따라 `온라인` 또는 `오프라인`이 앱 이름 옆에 표시된다.
* 채팅 영역은 메시지 목록만 스크롤되도록 독립 스크롤 영역으로 구성한다.
* 채팅 입력 영역 상단에는 채팅 기록 버튼과 대화 기록 저장 스위치가 포함된다.
* 대화 기록 저장 스위치를 켠 대화만 로컬 채팅 기록에 저장한다. 스위치를 켜기 전의 임시 대화도 같은 창에서 스위치를 켜면 현재 대화로 저장된다.
* 채팅 기록 버튼을 클릭하면 채팅 탭 전체가 기록 목록으로 전환된다. 저장된 대화는 자동 생성된 제목으로 표시하고, 항목 선택 시 이전 대화를 불러와 이어서 대화할 수 있다.
* 채팅 기록 목록은 좌측 드래그 핸들로 순서를 바꿀 수 있고, 우측 `x` 버튼으로 저장된 대화를 삭제할 수 있다.
* 메뉴바 아이콘 재클릭 또는 Header의 `×` 버튼으로 창을 숨기면 다음에 채팅 탭을 열 때 항상 새 대화로 시작한다. 저장 스위치를 켠 대화만 기록 목록에 남는다.
* 입력창 내부 좌측의 `+` 버튼으로 로컬 파일을 선택해 첨부할 수 있다.
* 채팅 입력부에 파일을 드래그 앤 드롭하면 첨부 파일로 추가된다.
* 첨부 파일은 한 번에 1개만 추가할 수 있으며, 파일 크기는 최대 5MB까지 허용한다.
* 첨부 파일은 입력부 상단에 미리보기 카드로 표시되며, 긴 파일명은 카드 폭에 맞춰 말줄임 처리한다.
* 전송된 사용자 메시지의 첨부 파일은 메시지 텍스트와 분리해 사용자 버블 상단에 별도 미리보기 카드로 표시하고, 카드가 길어지면 줄바꿈해 하단으로 이어진다.
* 이미지 첨부 파일은 `ImageHandler`가 base64로 변환한 뒤 Ollama 요청의 `messages[].images`에 포함해 선택한 로컬 모델에 전달한다. API 모드에서는 PNG로 정규화해 제공자별 이미지 형식으로 전달한다.
* `TextHandler`는 `txt`, `md`, `json`, `yaml`, `yml` 첨부의 본문 일부를 UTF-8 기준으로 추출하고, JSON은 읽기 쉬운 들여쓰기 형식으로 정리한다.
* `CsvHandler`는 `csv`, `tsv` 첨부의 컬럼명과 샘플 행을 요약한다.
* `PdfHandler`는 `pdf` 첨부에서 앞쪽 일부 페이지의 텍스트를 추출해 첨부파일 참고 내용으로 전달한다. 스캔 PDF, OCR, 표 구조 보존, 이미지/차트 분석은 지원하지 않는다.
* `DocxHandler`는 `docx` 첨부의 문단과 표 안의 텍스트 일부를 첨부파일 참고 내용으로 전달한다. 서식, 이미지, 주석, 변경 추적, 매크로는 분석하지 않는다.
* `XlsxHandler`는 `xlsx` 첨부의 시트명, 컬럼명, 샘플 행을 첨부파일 참고 내용으로 전달한다. 전체 행 분석, 수식 재계산, 피벗/차트/서식 분석은 지원하지 않는다.
* `PptxHandler`는 `pptx` 첨부의 슬라이드별 텍스트를 첨부파일 참고 내용으로 전달한다. PPT 제작, 디자인 생성, 이미지/차트/표 구조 분석, 발표자 노트, 수치 계산은 지원하지 않는다.
* `ChatService`는 텍스트, CSV/TSV, PDF, DOCX, XLSX, PPTX 첨부파일 참고 내용을 user message 본문과 metadata에 추가해 모델 요청에 포함한다.
* 내용이 많거나 복잡한 첨부파일은 일부 내용만 참고할 수 있음을 사용자용 문구로 안내한다.
* 지원 파일 형식은 이미지(`png`, `jpg`, `jpeg`, `gif`, `bmp`), 텍스트(`txt`, `md`, `json`, `yaml`, `yml`), 표 텍스트(`csv`, `tsv`), 문서/오피스(`pdf`, `docx`, `xlsx`, `pptx`)로 제한한다.
* 지원하지 않는 파일은 Assistant 메시지로 오류를 표시한다.
* 입력창은 `Enter`로 전송하고 `Shift+Enter`로 줄바꿈한다.
* 긴 입력 텍스트는 입력창 폭에 맞춰 자동 줄바꿈된다.
* Header의 설정 아이콘을 클릭하면 설정 화면으로 전환되고, `×` 버튼을 클릭하면 메인 창을 숨긴다.
* 할일은 생성 날짜별 제목과 얇은 구분선으로 그룹화한다. 완료 체크는 삭제하지 않으며 우측 `×`로 삭제한다. 같은 날짜 안에서 드래그 재정렬한다.
* 메모 탭은 로컬 SQLite 저장, 목록/편집 화면 전환, 자동 저장, 삭제, 드래그 재정렬을 지원한다.
* 새로운 메모를 클릭하면 바로 전체 메모 작성 화면으로 전환된다.
* 메모 입력은 Markdown 서식을 지원하며 제목, 목록, 체크박스, 인용, 인라인 코드, 코드 블럭을 편집 중 즉시 시각화한다.
* 메모 코드 블럭 안에서 `Enter`는 블럭을 닫고 밖으로 이동하며, `Shift+Enter`는 블럭 내부 줄바꿈을 유지한다.
* 메모 목록 카드 본문은 최대 2줄로 말줄임 처리되어 날짜 영역과 겹치지 않는다.

현재 설정 화면은 메인 화면과 Header·캐릭터·탭을 공유한다. 설정 아이콘 또는 뒤로 버튼으로 돌아가며, 채팅·할일·메모 탭을 눌러도 해당 화면으로 이동한다.

* 라이트/다크 테마와 한국어/영어 언어는 실제 적용되고 SQLite `preferences`에 저장되어 재실행 후 복원된다. 사용자 작성 내용은 번역하지 않는다.
* ‘시작 시 Myorii 열기’ 스위치는 표시만 구현되어 있으며 운영체제 자동 시작 설정에는 아직 연결되지 않았다.
* 제공자는 **Ollama 로컬 모델 / API** 두 버튼 중 하나만 선택한다.
* 로컬 모드는 실제 설치 모델 드롭다운과 모델 관리 버튼을 나란히 표시한다. 모델 관리에서는 비동기 목록 조회, 선택, 삭제를 지원한다. 현재 선택 모델 삭제는 막으며 다운로드 버튼은 Ollama 라이브러리 웹페이지를 연다.
* API 모드는 OpenAI·Gemini·Claude 서비스 선택, 보기/가리기 가능한 키 입력, 키 저장·삭제, 채팅용 모델 드롭다운을 제공한다. 키 저장 후 목록을 자동 조회하고, 드롭다운 오른쪽의 ‘목록 새로고침’으로 다시 조회한다. 모델 이름 직접 입력은 허용하지 않는다.
* API 키는 macOS 키체인에 저장하고 모델·제공자 선택만 SQLite에 저장한다. 외부 API 사용 시 대화·첨부가 해당 제공자에게 전달된다.
* 드롭다운 화살표는 오른쪽 중앙에 위치하며, 목록은 입력칸 바로 아래에 둥근 테두리로 표시한다.
* 연동은 **MCP · 커넥터 · 플러그인**으로 모델에 외부 도구와 서비스를 연결하는 향후 구현 안내다. 현재 연결 기능이나 Notion 전용 연동 버튼은 없다.
* 정보에는 버전, 도움말 사이트 추후 구현 안내, 문의 및 제안을 표시한다. 도움말 안내와 `heamin0603@naver.com`은 제목 오른쪽의 작은 글자이며 버튼·메일 전송 기능은 없다.
* 앱 종료 버튼은 실제로 애플리케이션을 종료한다.

## 실행 종료

설정 화면의 앱 종료 버튼을 누르면 Myorii를 종료한다.

개발 중 강제 종료가 필요하면 프로세스를 직접 종료할 수 있다.

```bash
pkill -f Myorii
```

터미널에서 `python main.py`로 실행한 경우에는 `Ctrl+C`로 종료할 수 있다.
