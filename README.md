# Myorii

macOS 메뉴바에서 채팅, 할일, 메모를 여는 Python 데스크톱 컴패니언.

현재 `main`에는 소개 문서만 있다. 실행 코드와 프로젝트 문서는 개발 통합 브랜치인 [dev](https://github.com/hazyala/myorii/tree/dev)에 있다. 이 브랜치를 clone해도 `main.py`나 의존성 파일은 내려오지 않는다.

[dev README](https://github.com/hazyala/myorii/blob/dev/README.md)에서 실행 방법, Ollama·외부 API 연결, SQLite 저장, 채팅으로 할일·메모를 다루는 흐름을 확인할 수 있다. Windows 지원, 클라우드 동기화, MCP·커넥터·플러그인 연결은 기존 로드맵의 향후 항목이다.

```bash
git clone --branch dev https://github.com/hazyala/myorii.git
cd myorii
```
